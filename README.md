# Математика и информатика

Репозиторий фронтенда образовательной платформы: SEO-ориентированный банк задач
по математике и информатике с ответами и пошаговыми решениями, статьи с
разборами и страница индивидуальных занятий.

## Состав репозитория

| Путь | Описание |
| --- | --- |
| [`frontend/`](frontend/) | Приложение на Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 |
| [`backend/`](backend/) | FastAPI API: задачи, статьи, заявки, пользователи и прогресс |
| [`ideal.html`](ideal.html) | Исходный HTML/CSS/JS-прототип. Сохранён как дизайн-референс; перенесён в `frontend/` и больше не является продакшн-страницей |

## Быстрый старт

```bash
cd frontend
pnpm install
cp .env.example .env.local   # при необходимости
pnpm dev                     # http://localhost:3000
```

Полная инструкция, список команд и переменные окружения — в
[`frontend/README.md`](frontend/README.md).

## Статус

Реализованы и проверены: миграция главной страницы, каталог задач с фильтрами и
пагинацией, страница задачи с проверкой ответа, статьи с оглавлением,
тематические хабы, страница занятий с формой заявки, SEO-инфраструктура
(metadata, canonical, robots, sitemap, JSON-LD, 404).

Бэкенд на FastAPI реализован в [`backend/`](backend/): задачи, статьи,
проверка ответов, заявки, авторизация и прогресс, миграции Alembic и seed-скрипт.
Фронтенд подключается к нему автоматически, когда задан `API_BASE_URL` /
`NEXT_PUBLIC_API_BASE_URL`; без него публичные страницы работают на
демонстрационных наборах.
